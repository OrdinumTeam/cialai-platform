## Resumo

Quem tem várias contas de agente ganhou um lugar para criar e trocar de conta, e o terminal pergunta qual conta usar quando você digita `codex` ou `claude`. O explorador de arquivos chegou perto do VS Code, com recortar, copiar e colar, seleção múltipla, desfazer e arrastar vários arquivos para fora do app. E cada card de agente mostra só o estado da própria sessão, mesmo com várias sessões do Codex na mesma pasta.

## Destaques

* **👥 Perfis de agentes.** Uma janela reúne as contas do Codex e do Claude Code com a cota de cada uma e, ao lado, um tutorial animado de como trocar de conta. Criar uma conta nova copia as instruções e a configuração da conta padrão e já abre o login numa sessão nova. Abre pela paleta de comandos, pelo menu do app, pelas Preferências e pelas contas do terminal.
* **🔀 A conta certa ao abrir o agente.** Nas sessões do Cialai, digitar `codex` ou `claude` com mais de uma conta mostra a lista com a cota de cada uma. Enter repete a última conta usada naquela pasta, um número troca de conta, a conta esgotada fica para trás e `codex +nome` vai direto. Funciona no zsh, no bash e no PowerShell.
* **✂️ Recortar, copiar e colar no explorador.** Pelo menu e pelo teclado, como no VS Code. Colar numa pasta com um arquivo do mesmo nome cria um nome livre, nunca sobrescreve.
* **☑️ Seleção múltipla.** Cmd ou Ctrl marca um arquivo de cada vez, Shift marca a faixa e Cmd A marca tudo. Recortar, copiar, copiar caminho e mover para a Lixeira valem para a seleção inteira, com a contagem no diálogo.
* **↩️ Desfazer e refazer.** Cmd Z desfaz renomear, mover, copiar e criar, e Cmd Shift Z refaz. Mover para a Lixeira continua indo para a Lixeira do sistema. F2 renomeia.
* **📤 Vários arquivos para fora do app.** Arrastar uma seleção leva todos os arquivos para o Finder, para uma pasta ou para o WhatsApp.
* **📍 O arquivo aberto aparece na árvore.** Abrir um arquivo no editor revela e destaca onde ele está no explorador.
* **🟢 Cada card com o estado da própria sessão.** Com várias sessões do Codex na mesma pasta, os cards mostravam o mesmo estado, como Resposta entregue. Agora cada um lê o que o Codex escreve no próprio terminal, e o card mostra Aguardando você quando o Codex pede permissão. A Barra de IA lista cada conversa do Codex em andamento.
* **📐 Botões alinhados na tela vazia.** Nova sessão e Vincular celular ficam na mesma altura, com espaço entre eles, inclusive quando a janela estreita quebra a linha.

## Atualizar

O atualizador embutido encontra sozinho. No macOS e no Linux também vale `curl -fsSL https://cialai.com.br/install.sh | bash`. No Windows, pelo `.exe` ou pelo `.msi`.

## Notas da entrega

Os apps do celular não mudaram. A página do celular vem do computador, então quem atualiza o computador já recebe no celular os cards com o estado certo de cada sessão.

O menu de contas só aparece nas sessões abertas pelo Cialai, e só quando o agente roda sem argumentos. Para desligar, use `CIALAI_AGENT_MENU=0`.

Uma sessão do Codex atendida pelo servidor compartilhado dele mostra o estado certo, mas fica sem retomada automática da conversa depois de reiniciar o computador, até o Codex informar qual conversa é de qual terminal. Antes ela retomava a conversa de outra aba.

## Verificação

* **Suíte local.** O `npm test` completo passou com Node 22, com 437 testes de interface, e os 473 testes do Rust passaram, com o clippy e o formatador limpos.
* **Estado por sessão com o Codex real.** Três abas do Codex 0.164 na mesma pasta, com o servidor compartilhado nascido na árvore de uma delas. Um turno só na terceira levou o card dela de Processando a Resposta entregue, e os outros dois ficaram em Pronto para instrução. O servidor ficou fora da árvore das abas e nenhuma recebeu a conversa de outra. O pedido de permissão do Codex apareceu como espera.
* **Interface no navegador.** Os botões da tela vazia foram medidos no claro, no escuro e no Windows, de 1280 a 440 px, sem desnível. O explorador foi conferido com seleção múltipla, menu do lote, recortar e colar, sem erro no console. O modal de perfis foi conferido no claro, no escuro, estreito e no Windows.
