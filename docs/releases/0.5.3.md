## Resumo

O uso do Claude Code no plano Ultra aparece logo ao abrir o Cialai, mesmo quando o Claude limita as consultas de uso. Na 0.5.2 o número só voltava depois de uma leitura nova.

## Destaques

* **Uso do plano Ultra ao abrir.** A leitura guardada por versões anteriores ficava sem a janela do anel nas contas sem limite de cinco horas. O Cialai agora escolhe a semana também para essa leitura, então o card e o anel mostram o número sem esperar a próxima consulta.

## Arquivos

O Cialai 0.5.3 traz os instaladores de macOS, Windows e Linux. Os aplicativos do celular continuam nas versões publicadas, sem submissão nova às lojas. O Broto tem release própria, a 0.1.4.

## Atualizar

Use o atualizador do Cialai ou os instaladores em https://cialai.com.br/downloads/. No Windows, `powershell -c "irm https://cialai.com.br/install.ps1 | iex"` instala pelo cmd ou pelo PowerShell.
