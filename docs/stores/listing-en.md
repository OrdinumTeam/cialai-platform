## Full description

<!-- STORE_LONG_START -->
```text
Cialai brings your desktop terminal studio to your phone without sending your projects to a service hosted by Ordinum.

On desktop, each session opens a real shell in a folder you choose. You can follow the running process, resource use and coding agent state. The same workspace brings together files, Git changes, local previews and a controlled Chromium browser.

On your phone, you can follow terminal history, take control of the session, use essential keys and browse the files you allowed. The header always shows the active computer and connection state.

Key features:

• Terminal sessions organized by project
• Local history preserved after the application closes
• Resume support for compatible Claude Code and Codex sessions
• Files, Git, previews and Dev Browser on desktop
• Pairing with a short lived QR code
• Device revocation from the desktop
• Biometric protection for sensitive actions on mobile
• End to end encrypted connectivity between paired devices
• Automatic connection, direct when the network allows and through Tor as backup

Cialai requires the desktop application open on your computer. There is no server to set up: your phone connects directly when the network allows and through the Tor network as backup. Ordinum does not operate a Cialai cloud and does not receive your project or terminal content.

Read the privacy policy and project documentation to learn which public networks the connection uses.
```
<!-- STORE_LONG_END -->
