## Cialai Broto 0.1.2 preview

Send, receive and list files at paths accessible to the account running Broto, including mounted volumes and system folders. Absolute paths, paths relative to the account home and symbolic links use the account's operating system permissions.

Transfers retain SHA256 verification, progress, explicit overwrite, cancellation and destination locking. Existing pairing, Pause, Disconnect and the host's operation permissions remain available.

Installers are available for Windows x64 and Linux x64, with DEB and RPM packages. Update Broto on the remote computer to receive this functionality. This is an independent Broto release and works with the file commands in Cialai 0.5.1.

Downloads and automatic updates use the separate Broto channel at [cialai.com.br/broto](https://cialai.com.br/broto). Verify the signed checksums with the independently trusted Broto key.

Source validation is recorded in [the Broto 0.1.2 evidence](https://github.com/OrdinumTeam/cialai-platform/tree/main/docs/evidence/broto-0.1.2).
