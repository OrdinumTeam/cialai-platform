# Marcas dos provedores

Os arquivos SVG desta pasta vem do pacote npm `@lobehub/icons-static-svg`
1.95.0, https://github.com/lobehub/lobe-icons, licenca MIT. Chegaram ao
Cialai pela Barra de IA do Ordinum Control, que os recebeu da porta Windows
do Codenotch, https://github.com/vinzdg/codenotch, tambem MIT.

| Arquivo | Origem no pacote | Onde aparece |
| --- | --- | --- |
| `claude.svg` | `icons/claude.svg` | anel de um perfil do Claude Code |
| `openai.svg` | `icons/openai.svg` | anel de um perfil do Codex |

Mudancas em relacao ao original: o bloco `<metadata>` com a proveniencia C2PA
foi retirado, porque so descreve o arquivo e pesava mais que o desenho; e
`width` e `height` passaram de `1em` para `24`, com o estilo inline removido,
para o SVG servir tanto inline quanto como imagem.
