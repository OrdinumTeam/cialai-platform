# Security policy

Cialai has no supported production release yet. Phase 0 code is experimental.

Do not post credentials, pairing QR payloads, private files or exploitable details
in public issues. Report a vulnerability through GitHub private vulnerability
reporting if it is enabled for this repository. Otherwise, use a private contact
channel listed on a maintainer's GitHub profile to request a secure reporting route.

Include the affected revision, reproduction steps, expected impact and sanitized
evidence. Do not test against another person's devices or Headscale server.

A dedicated security email, acknowledgment deadline and supported-version policy
must be confirmed by the maintainers before public launch. No unverified address
or response commitment is advertised at this stage.
